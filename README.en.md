## Background

A `.app` downloaded from the internet (browser, messenger) carries the quarantine attribute
(`com.apple.quarantine`). It won't open directly — you have to go to System Settings →
Privacy & Security and click "Open Anyway". AGO is a small macOS utility that finishes
that chore with a single drag.

## Use Cases

- Opening a `.app` you received without a DMG, or one that refuses to launch right after unzipping
- Quickly handling cases where the problem is the **quarantine flag**, not a damaged app
- Letting **tampered apps through only after a warning**, never silently

## Usage

1. Drop the `.app` onto the AGO window (or press `⌘O` to pick it)
2. The pipeline runs automatically to the end: inspect → unquarantine → verify → assess
3. Press the **Run button yourself** when it becomes enabled (never auto-launches)

## Message Reference

| Message | Meaning | What to do |
|---|---|---|
| `차단 속성 제거됨` (quarantine removed) | Quarantine flag removed | Continue |
| `서명 정상` (signature valid) + Gatekeeper accepted | All checks passed | Launch with the Run button |
| `변조 의심` (tampering suspected: N files added/modified) | Files don't match the signature (e.g. dylib injection) | Read the red warning card → reinstall from the official source is recommended. To run anyway, tick the checkbox, then run |
| `개발용 서명` (development signature rejected by Gatekeeper) | Signed with a development certificate, not for distribution. Not malware | Check the warning card → tick the checkbox, then run |
| `Gatekeeper가 실행을 거부했습니다` (Gatekeeper refused) | Assessment failed, with tampering evidence | Cannot run. Download again from the official source |
| `차단 속성 제거에 실패했습니다` (failed to remove quarantine) | Permission problem (usually inside `/Applications`) | Move the app elsewhere (e.g. `~/Downloads`) and retry |

## Security Policy

What it will never do:

- No forced re-signing (`codesign --force`) — it would pave over tampering evidence
- No automatic `sudo` escalation
- No launching without your confirmation
- No `.dmg` handling (out of scope for v1)

## Install

1. Download `AGO-<version>-macos.zip` from [Releases](https://github.com/BoraSarang/AGO/releases)
2. Unzip and copy `AGO.app` to `/Applications`
3. On first launch macOS may block it (unsigned build): run
   `xattr -dr com.apple.quarantine ~/Downloads/AGO-*.zip` before unzipping

## Build from source

Requires: Xcode 26+, [xcodegen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`)

```bash
xcodegen generate
./build_and_run.sh build macos   # installs to ~/Applications/AGO.app
./build_and_run.sh test macos unit
./build_and_run.sh package macos # → dist/AGO-<version>-macos.zip (override with VERSION=0.2.0)
```

> `Sources/AGO/Info.plist` is generated by xcodegen. Do not edit it directly —
> declare keys in `project.yml` under `info.properties`.
