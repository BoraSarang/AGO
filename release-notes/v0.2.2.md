## v0.2.2 — 실행 런처 수정 + 자동 업데이트 확인

macOS 26에서 미인정 서명 앱이 "확인할 수 없습니다"로 막히던 문제를 해결하고,
이제는 **앱 안에서 새 버전을 알려드립니다**.

### 주요 변경
- **실행 위임 방식 개선**: AGO가 직접 앱을 열면 macOS Gatekeeper가 차단하던 문제 해결.
  이제 정품 **터미널을 경유**해 사용자 세션과 동일한 방식으로 실행합니다
  (최초 1회 "AGO가 터미널을 제어하려고 합니다" 허용 필요 — 일반 권한 허용입니다)
- **생존 감지 버그 수정**: macOS 26에 사라진 `/bin/pgrep` 경로 오류로 앱이 떴는데도
  "실행 실패"로 표시되던 문제 수정 + 프로세스 확인 재시도 로직 추가
- **서명 건너뛰기 체크박스**: 하단바에 기본 체크 상태로 추가 — 확인 창 없이 바로 검사·실행
- **출처 속성 정리 강화**: `com.apple.provenance`·`com.apple.macl` 함께 제거 (macOS 26 대응)

### 업데이트 확인 (신규)
- **하단 버전 표시**가 새 버전이 있으면 주황색 "vX.Y.Z 사용 가능" 배지로 변경 → 클릭 시 릴리스 노트 시트
- **도움말(⌘/) → 업데이트 확인**: 즉시 확인 + 확인 주기 선택 (실행 시/매일/매주/안 함, 기본 주 1회)
- 새 버전은 **DMG 다운로드 → Applications로 교체**하는 방식 (자동 교체 없음 — Gatekeeper 보호 유지)

### 다운로드 후
1. `AGO-0.2.2-macos.dmg`를 내려받아 열기
2. AGO.app을 **응용 프로그램** 폴더로 드래그 (기존 버전이 있으면 교체)
3. 첫 실행 시 "확인할 수 없습니다"가 뜨면 **우클릭 → 열기** (한 번만 하면 됩니다)
