# v0.3.1 — 도움말 UX 강화 (Help sheet)

**릴리스 날짜**: 2026-09-24
**테스트**: 49/49 통과

## 주요 변경

### 도움말 시트 7섹션 전면 개편
- 기존 4섹션 + 신규 3섹션 추가:
  - **파일 형식별 처리** — `.app` / `.dmg` / `.pkg` 각각 어떻게 처리되는지
  - **준비됨과 경고** — 어떤 상태가 안전하고 어떤 상태가 판단이 필요한지
  - **자주 나오는 문제** — 권한 문제, Gatekeeper 거부, 변조 의심 등 FAQ
- 표시 순서: 왜 필요한가요 → 사용 절차 → 파일 형식별 처리 → 준비됨과 경고 → 경고의 의미 → 하지 않는 일 → 자주 나오는 문제
- **업데이트 행 하단 고정** — 스크롤과 무관하게 항상 노출
- 시트 크기: 420×380 → **480×560**

### 첫 실행 1회 자동 표시
- `ago.helpSeen` 플래그로 **첫 실행에만** 도움말 시트 자동 표시
- 닫으면 이후 자동 표시되지 않음 (온보딩 반복 없음)
- XCTest 호스트에서는 자동 표시 스킵 (테스트와 시트 경쟁 방지)

### 드롭존 링크 추가
- 빈 상태에서 `파일 선택…` 옆에 **`도움말 보기 ⌘/`** 링크
- `⌘/` 툴팁 지원

### 로케일
- ko/en **143키 parity** (신규 8키: `help.s5t/s5b/s6t/s6b/s7t/s7b`, `drop.helpLink/drop.helpLinkHelp`)

### 문서
- README·README.ko 사용 방법·설치 절차에 도움말 반영
- 랜딩 페이지 EN/KO 버전 표기 v0.1.0 → **v0.3.1**, 사용법·메시지 표 갱신
- CHANGELOG·TODO·DESIGN·세션 로그 갱신

## 버그 수정
- Gatekeeper 거부 메시지 대응: 경고 카드 + 체크박스 게이트 안내로 정확화 (ko/en)

## 설치

1. `AGO-0.3.1-macos.dmg` 다운로드
2. `AGO.app`을 `/Applications`로 드래그
3. 첫 실행 시 차단 경고 → 우클릭 → 열기 (1회)
4. 도움말 시트가 한 번만 열림 — 닫으면 그 다음부터 자동 표시 없음
