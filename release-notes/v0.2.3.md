## v0.2.3 — 손상 앱도 열리게 (spctl 경고 게이트) + 확인 단계 멈춤 수정

서명이 깨진 앱(예: 중첩 플러그인 불일치)을 AGO가 **완전 차단**하던 문제를 고치고,
대량 출력에서 확인 단계가 무한히 멈추던 데드락을 해결합니다.

### 주요 변경
- **spctl 거부 → 경고 게이트**: 차단 속성 제거까지 끝났다면 Gatekeeper 재평가가 없습니다.
  이제 spctl이 거부해도 **빨간 경고 카드 + 체크박스**로 열립니다 (기존: 실행 불가)
- **재귀 속성 검사**: `xattr -l`이 루트만 보던 문제 수정 — 폴더 안쪽 파일에만 있는
  quarantine/provenance/macl도 감지·제거합니다
- **확인 단계 멈춤 수정**: `xattr -lr` 출력이 시스템 파이프 버퍼를 넘으면
  프로세스가 영원히 대기하던 데드락 해결
- **서명 실패해도 계속**: 재서명이 불가능한 앱도 검사·실행으로 진행
  (부분 서명으로 봉인을 더 깨뜨리지 않도록 중첩 실패 시 본체는 서명하지 않음)

### 다운로드 후
1. `AGO-0.2.3-macos.dmg`를 내려받아 열기
2. AGO.app을 **응용 프로그램** 폴더로 드래그 (기존 버전 교체)
3. 첫 실행 시 "확인할 수 없습니다"가 뜨면 **우클릭 → 열기** (한 번만)
