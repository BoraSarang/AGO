# v0.3.2 — 문서·랜딩 메타데이터 정비 (기능 변경 없음)

**릴리스 날짜**: 2026-10-25
**테스트**: 49/49 통과

이번 릴리스는 **앱 동작이 바뀌지 않는 문서 릴리스**입니다. 앱 로직·L10n·UI는 v0.3.1과 동일하고, 저장소와 소개 페이지의 메타데이터만 정리했습니다.

## 주요 변경

### README 배지
- `README.md` · `README.ko.md` 상단에 동일한 배지 4종: **macOS 14+ · Swift 6 · SwiftUI · MIT**
- 한/영 문서 첫 화면에서 플랫폼·스택·라이선스를 바로 확인 가능

### GitHub topics 정리
- 플랫폼·언어: `macos` `macos-app` `swift` `swiftui`
- 기능·도메인: `gatekeeper` `codesign` `quarantine` `security-tools`
- 배포·분류: `dmg` `universal-binary` `apple-silicon` `intel` `desktop-utility`
- 기타: `xcodegen` `korean`
- 배포물이 **universal(x86_64 + arm64)** 임을 `lipo`로 확인해 `universal-binary`·`intel` 포함

### 소개 페이지 (EN / KO)
- `meta description` 보강 — quarantine·codesign·Gatekeeper 키워드 반영
- `meta keywords` · canonical · Open Graph · Twitter Card 추가
- **구조화 데이터(JSON-LD, SoftwareApplication)**: 버전·운영체제·라이선스·무료 여부·저장소 링크 명시
- 푸터에 **Topics 한 줄** 추가 (저장소 topics와 동일한 키워드)
- 버전 표기 v0.3.1 → **v0.3.2**

## 설치

1. `AGO-0.3.2-macos.dmg` 다운로드
2. `AGO.app`을 **응용 프로그램** 폴더로 드래그 (기존 버전 교체)
3. 첫 실행 시 "확인할 수 없습니다"가 뜨면 **우클릭 → 열기** (한 번만)
