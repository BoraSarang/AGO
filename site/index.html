A downloaded app won't open?
Drop it once. That's it.

AGO unquarantines the .app, verifies its signature, asks Gatekeeper — and only launches when you press Run. Tampered apps stop at a red warning, never run silently.

Download for Mac GitHub

Free · macOS 14+ · Apple silicon & Intel · unsigned build (one manual unblock on first install)

Background

Apps downloaded from a browser or messenger carry the quarantine flag (com.apple.quarantine), so macOS won't open them until you dig through System Settings → Privacy & Security and click “Open Anyway”. AGO turns that chore into a single drag.

Use Cases

No-DMG apps

Open a plain .app that refuses to launch right after downloading or unzipping.

It's the flag, not damage

Quickly clear cases where quarantine — not corruption — is the blocker.

Warning, then it's your call

Broken signatures surface as a red card with the exact files. The call is yours.

Usage

  1. Drop the .app

    Drag it onto the window, or press ⌘O to pick a file.

  2. Watch it inspect itself

    Inspect → unquarantine → verify → assess, all automatic with a live log.

  3. Press Run yourself

    The button enables only on pass — or after you tick the warning checkbox. Never auto-launches.

Message Reference

Every outcome maps to one follow-up. No guessing.

MessageMeaningFollow-up
done
quarantine removed		Flag cleared.Continue — nothing to do.
ready
signature valid + accepted		All checks passed.Press Run.
warning
tampering suspected		Files don't match the signature (e.g. injected dylib).Read the red card. Reinstall from the official source — or tick the checkbox and run at your own risk.
warning
development signature		Dev-certificate build, not for distribution. Not malware.Check the card, tick the checkbox, run.
blocked
Gatekeeper refused		Failed assessment with tampering evidence.Cannot run. Download again from the official source.
failed
couldn't remove quarantine		Permission problem, usually inside /Applications.Move the app (e.g. to ~/Downloads) and retry.

Security Policy

  • No forced re-signing — it would pave over tampering evidence.
  • No automatic sudo escalation.
  • No launching without your confirmation.
  • No .dmg handling (out of scope for v1).
