열어줘 AGO · Automatic Gate Opener
EN · 한국어
macOS 유틸리티 · v0.3.1

받은 맥 앱이 열리지 않을 때,
드래그 한 번이면 됩니다.

열어줘는 .app·.dmg·.pkg의 차단 속성을 해제하고 서명을 검증해 Gatekeeper 평가까지 마친 뒤, 직접 누른 실행 버튼으로만 실행합니다. 변조된 앱은 빨간 경고 카드에서 멈추고, 몰래 실행되지 않습니다. 첫 실행에는 도움말 시트가 한 번만 열려 각 상태의 뜻을 알려줍니다.

Mac용 다운로드 GitHub

무료 · macOS 14+ · Apple Silicon/Intel · 서명 없는 배포판이라 첫 설치 시 한 번의 수동 해제가 필요합니다

개발 배경

브라우저·메신저로 받은 앱에는 차단 속성(com.apple.quarantine)이 붙어 있어 바로 실행되지 않습니다. 시스템 설정 → 개인정보 보호 및 보안에서 “확인 없이 열기”를 눌러야 하는데, 열어줘는 그 수고를 드래그 한 번으로 끝냅니다.

사용 사례

DMG·PKG·앱

다운로드하거나 압축을 푼 직후 실행이 막히는 .dmg·.pkg·.app을 열 때.

고장이 아니라 차단

앱이 손상된 것이 아니라 차단 속성 때문에 실행되지 않는 경우를 빠르게 해소할 때.

경고 후 판단

서명이 깨진 앱은 빨간 경고 카드에 변경된 파일까지 표시합니다. 실행 여부는 사용자가 결정합니다.

사용 방법

  1. .app / .dmg / .pkg을 창에 놓는다

    드래그하거나 ⌘O로 파일을 선택합니다. 첫 실행에는 도움말 시트가 한 번만 열립니다 (7섹션) — 닫으면 다음부터 자동으로 뜨지 않으며 ⌘/로 언제든 다시 열 수 있습니다.

  2. 검사가 자동으로 진행된다

    확인 → 제거 → 검증 → 평가까지 실시간 로그와 함께 처리됩니다. .dmg는 내부 앱(설치 DMG는 패키지)을 추출한 뒤, .pkg는 설치기 열기 전까지 검사합니다.

  3. 직접 실행한다

    모든 검사가 통과되면 실행 버튼이 활성화됩니다. 경고가 있다면 체크박스를 확인한 뒤에 활성화되며, 자동 실행은 없습니다.

메시지별 대응 방법

각 결과에는 정해진 대응이 하나씩 있습니다.

메시지의미대응
완료
차단 속성 제거됨		차단 해제 성공.그대로 진행합니다.
준비됨
서명 정상 + 통과		검사 전부 통과.실행 버튼을 눌러 실행합니다.
경고
변조 의심		서명과 파일 불일치 (dylib 주입 등).빨간 카드를 살펴봅니다. 공식 출처에서 재설치하는 것이 좋으며, 그래도 실행하려면 체크박스를 선택한 뒤 실행합니다.
경고
개발용 서명		개발 인증서로 서명되어 배포용으로 인정되지 않습니다. 악성은 아닙니다.카드를 확인하고 체크박스를 선택한 뒤 실행합니다.
경고
서명 신원 발견 → 서명 완료		본인 개발자 신원으로 서명됨.Gatekeeper 평가는 별도입니다. 카드를 확인하고 체크박스를 선택한 뒤 실행합니다.
차단
Gatekeeper 거부		변조 증거와 함께 평가가 실패했습니다.경고 카드 + 체크박스가 뜹니다. 카드를 확인한 뒤 체크박스를 선택하면 실행할 수 있습니다 (터미널 위임).
실패
차단 해제 실패		권한 문제 (주로 /Applications 내부).다른 폴더(예: ~/Downloads)로 옮긴 뒤 다시 시도합니다.

보안 정책

  • 익명 재서명(adhoc)을 하지 않습니다. 변조 증거를 덮어버리기 때문입니다.
  • 개발자 신원 서명은 항상 사용자 확인을 거친 뒤에만 진행합니다.
  • sudo를 자동으로 승격하지 않습니다.
  • 확인 없이 자동으로 실행하지 않습니다.
  • .pkg는 설치기 열기까지만 지원하며 재서명하지 않습니다.
