# DESIGN - AGO (열어줘) macOS 앱

> **기준**: `macos-app-design` + `apple-design` (딱 맥 앱 같아야 함)
> **방향**: 풀커스텀 콘텐츠 + 네이티브 크롬 (2026-09-07 확정)
>   - 커스텀: 히어로 드롭존 · 파이프라인 타임라인 · 터미널 카드 · 경고 카드
>   - 네이티브 유지: 트래픽라이트 · unified 툴바 · 메뉴바 · 단축키 · Window 복원 (타이틀바 숨김 안 씀)
> **최종 갱신**: 2026-09-24 (도움말 7섹션·첫 실행 1회 표시·업데이트 행 고정)

---

## 1. 윈도우
- 단일 윈도우 520×640 (최소 480×560), compact 유틸리티 규격
- `.windowToolbarStyle(.unified)`, 트래픽라이트 숨기지 않음
- 핀 켜짐 시 `window.level = .floating`, 상태 `@AppStorage("agoPinned")` 복원
- 종료 버튼 = 앱 종료 (`applicationShouldTerminateAfterLastWindowClosed → true`)

## 2. 레이아웃 (위→아래)
1. 툴바: 상태 배지(좌) + 핀 버튼(우, `⌘T`)
2. 파이프라인 타임라인: `확인 → 제거 → 검증 → 서명 → 실행` 5단계, 단계별 스피너·체크·에러 아이콘. 현재 단계만 accent. 서명 스킵 시 서명 단계는 완료(스킵)로 표시
3. 히어로 드롭존: 큰 드롭 타깃 카드, 빈 상태는 SF Symbol 일러스트 + `.app` 드래그 문구 + "파일 선택…" · "도움말 보기 ⌘/" 2버튼 병행
   - 앱 수락 후: 앱 아이콘(NSWorkspace) + 이름·버전 미리보기로 교체
   - 드래그 중 2pt accent 하이라이트
4. 터미널 로그 카드: `.regularMaterial` 위 SF Mono 12pt, 행 높이 1.4×, 명령(`$`) / 성공(초록) / 에러(빨강) 색 구분, 자동 스크롤 + 복사 버튼 + 여러 줄 선택 (통짜 검은 박스 금지)
5. 경고 카드(조건부): 빨간 틴트, 변조 파일 수 + 상위 5개 목록, 공식 재설치 권장, "위험을 알고 실행" 체크박스
6. 실행 버튼: `ready`에서만 활성화. `blocked`는 체크박스 확인 후 활성화
7. 서명 확인 다이얼로그(조건부): 검증 완료 후 "서명하시겠습니까?" + `[서명하기]`/`[건너뛰기]`. 신원 미등록 시 유도 시트로 전환 (Xcode 열기 + 다시 확인 + 수동 입력). 비번 수집 없음
8. 하단: 서명 스킵 체크박스 · 도움말 · 버전/업데이트 배지 · 문의/GitHub · 종료
9. 도움말 시트 (480×560): 본문 7섹션 스크롤 + **업데이트 확인 행·푸터 하단 고정**. 첫 실행 1회 자동 표시 (`ago.helpSeen`), 이후 ⌘/·하단 링크·드롭존 링크로만 열기

## 3. 메뉴바
- App / File / Edit / View / Window / Help 최소 구성
- 도움말 `⌘/`, 핀 토글 `⌘T`, 종료 `⌘Q` (시스템 표준 재지정 금지)

## 4. 색·서체
- 시맨틱 컬러 + `.regularMaterial` (Liquid Glass는 시스템 자동, 커스텀 글래스 남발 금지)
- 본문 SF Pro 13pt, 로그 SF Mono 12pt, 숫자 `monospacedDigit`
- 호버 0.10~0.15s `.easeOut`

## 5. 키보드
- 모든 액션 단축키 보유. 드롭존 `Tab` 포커스 + `Space/Return`으로 파일 선택 열기

## 6. 모션·호버 (풀커스텀)
- 호버 0.10~0.15s `.easeOut`, 드롭 타깃 시 2pt accent 라인, 성공 시 체크 심볼 이펙트
- 느린 애니(0.3s+) 금지. 커스텀 글래스 남발 금지 (Liquid Glass 충돌 방지)
